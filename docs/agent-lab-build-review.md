2026-11-22 · Windows x64

## 남은 운영 검증과 구현

- 승인 Bun 실행 파일, GJC 오프라인 SDK 번들과 사내 Provider가 필요하다. SDK의 Windows 네이티브 모듈 로드, 실제 모델 응답 및 세션 이동, 툴 권한과 읽기 전용 네이티브 위임은 이 환경에서 확인하지 못했다.
- SDK Coordinator·Managed 오케스트레이션, 네이티브 쓰기 Executor와 장기 자율 워크플로는 미구현이다. 현재 실험은 등록된 계산만 실행한다. 임의 코드 실험을 위한 Windows OS 격리 및 Job Object 감독도 미구현이다.
- 승인 JSON 어댑터를 지원한다. 사내 SQL·MCP 원본 연결은 미구현이며, 공유 드라이브 기반 동시 접근과 장시간 장애 복구는 별도 검증이 필요하다.
- 연결 비교의 각 대리 조건은 합성 과제에서 후보를 골라 Router 평가로 넘긴다. 7개 조건 전체에 대한 실제 모델 학습, 새 연구 분야에서의 이전 성능, 장기간 독립적인 성능 향상은 측정하지 않았다.
