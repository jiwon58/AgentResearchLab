## Windows SDK 프로토타입 검증

Bun 1.4.5와 GJC SDK·Windows 네이티브 패키지 0.22.0을 임시 검증 번들에 고정했다. 루프백 목업에서 실제 SDK 모델 스트리밍, 이벤트, 세션 저장·복원 및 병렬 세션 3개의 생성이 통과했다. 별도 진단에서는 메모리에서 합성 표식만 반환하는 제한 도구의 호출 1건을 관측했다.

Lab의 `gjc` 런타임으로 합성 제조 연구를 실행해 작업 25개를 완료했다. SDK의 역할별 세션 파일 5개를 확인했고, SQLite를 다시 열어 독립 재현 `PASS`를 확인했다. 이전 시간의 온도 가설은 보류 데이터의 위험차 +24.24%p로 사전 기준을 통과했다. 측정 신뢰성과 검정력 계획이 미검증이어서 연구의 과학적 판정은 `INCONCLUSIVE`였다.

후속 검증에서 Lab의 기본 검토 어댑터를 활성화하고 SDK 내장 Planner·Architect·Critic과 `deep-interview`·`ralplan`의 연구용 자문 흐름을 실행했다. SDK는 하위 모델에 결과 제출용 `yield`와 지표 보고용 `report_metric`만 제공했다. 승인 전 하위 호출은 없었고 각 결과는 `ADVISORY`로 저장됐다. `ralplan`은 세 역할을 순서대로 호출해 앞선 자문을 다음 역할에 전달했다.

## 남은 운영 검증과 구현

- 사내 Provider를 사용한 모델 응답 및 위임과 세션 디렉터리 이동을 검증하려면 승인된 사내 환경이 필요하다.
- SDK Coordinator·Managed 오케스트레이션, 네이티브 쓰기 Executor와 장기 자율 워크플로는 미구현이다. 현재 실험은 등록된 계산만 실행한다. 임의 코드 실험을 위한 Windows OS 격리 및 Job Object 감독도 미구현이다.
- 승인 JSON 어댑터를 지원한다. 사내 SQL·MCP 원본 연결은 미구현이며, 공유 드라이브 기반 동시 접근과 장시간 장애 복구는 별도 검증이 필요하다.
- 연결 비교의 각 대리 조건은 합성 과제에서 후보를 골라 Router 평가로 넘긴다. 7개 조건 전체에 대한 실제 모델 학습, 새 연구 분야에서의 이전 성능, 장기간 독립적인 성능 향상은 측정하지 않았다.
