# 초기 구현 설계 및 검증

2026-11-22 · Windows x64

## 실행 구조

`apps/lab`의 CLI와 로컬 HTTP 서버가 TypeScript 연구 패키지를 호출한다. `contracts.ts`는 버전이 고정된 Preset과 Proposal 계약을 관리하고, `agents.ts`의 AgentRuntime이 JSON 제안을 반환한다. `store.ts`는 프로젝트와 역할, 예산, 선행 작업, 근거 참조, 중복 여부를 검증한 뒤 SQLite 트랜잭션에서 제안 및 작업 상태를 기록한다. 명세의 다른 연구 유형을 Preset에 표현할 수 있고, 현재 실행기는 제조 공정 연관성 평가에 연결되어 있다.

의존성 간선은 같은 프로젝트에서 이미 존재하는 작업에만 추가된다. 작업 획득은 단일 트랜잭션으로 이루어지며, 역할별 진행 중인 작업에 고유 제약을 적용한다. 만료된 Lease는 재시도 한도 내에서 회수되고 기존 토큰은 결과를 제출할 수 없다. 일시정지는 신규 작업 획득을 막고 이미 실행 중인 작업의 결과와 후속 제안을 보존한다. 취소 및 최종 실패는 막힌 하위 작업으로 전파된다. `run` API와 CLI는 지속 상태에서 다음 작업을 선택한다.

연구 Ledger와 Progress Ledger는 동일한 작업·이벤트 저장소를 조회한다. 프로젝트마다 Resident Identity, Genome 식별자, 세션 참조를 기록하며, 개인 기억은 프로젝트와 소유 역할로 조회를 제한한다. 실험 전에 데이터 분할, 방향, 최소 효과, 그룹 최소 크기와 임곗값을 고정한다. 실험 결과는 파일 해시로 식별하고 별도 계산 경로가 검증한다. 인과 식별 및 검정의 엄격성은 `NOT_EVALUATED`다. 해당 데이터에서 일정 수준의 관찰 연관성을 찾는 테스트다.

Rust 실행기는 `v1` 프로토콜의 제한된 정수 인자로 Dung Grounded Semantics와 유전 연산을 계산한다. 모델 응답에서 외부 프로세스, 셸, URL 또는 임의 실험 코드를 선택할 수 없다. 로컬 API는 루프백과 호스트·출처 검사로 제한된다. 여러 사용자 계정을 위한 원격 인증, 임의 실험을 실행하는 OS 샌드박스 및 Windows Job Object 감독은 미구현이다.

## AgentDeck 형식 Router 검증

AgentDeck의 Router 프로필 필드, OpenAI Chat Completions와 Anthropic Messages의 프로토콜 경로, Bearer 인증 방식을 적용했다. 직접 HTTP 호출은 별도의 AgentRuntime이며 Run은 Router 바인딩 해시를 저장한다. Bun 및 GJC SDK 호스트 경로와 병존한다.

Windows 루프백 목업에서 두 프로토콜 각각 `PONG` 연결 확인 후 연구를 시작했다. Director, Hypothesis Scientist, Skeptic의 모델 요청 10건씩이 지정된 HTTP 경로를 사용했다. 두 런 모두 `SUCCESS`였으며, 잘못된 대상 역할 제안은 거절됐고 독립 재계산은 `PASS`였다. 보안·오류 테스트에서 미승인 호스트, 리다이렉트, 인증 실패, 요청 제한, 과대 응답, 잘못된 JSON, 토큰 에코, 타임아웃을 확인했다. CLI 무인증 모드에서는 환경에 있던 시험용 토큰도 전송하지 않았다. 실제 사내 Router와 Codex API, GJC SDK 세션 호환성은 이 목업 검증 범위 밖이다.

## Windows 작업 폴더와 대시보드

선택한 작업 폴더마다 SQLite, 실험 산출물 및 SDK 세션 디렉터리를 `.gajae-lab`에 둔다. 요청과 백그라운드 작업은 시작할 때의 폴더 식별자로 고정한다. 연구 설정, 에이전트 기억, 작업 이력, 평가와 체크포인트는 연결할 폴더에서 읽는다. `LAB_DB` 모드의 기존 기록은 그대로 열 수 있다.

Windows 자동 테스트에서 두 작업 폴더를 연결하고 한쪽의 Run, 저장 설정, 실험 파일, 진화 평가가 다른 폴더에 나타나지 않는 것을 확인했다. 서버를 종료하고 해당 폴더 이름을 바꾼 뒤 Run, 아티팩트, 평가가 복원됐다. `.gajae-lab`을 다른 폴더로 연결하는 Windows junction은 열기 전에 거절했다. 실제 GJC SessionManager의 경로 변경 복원은 미검증이다.

Chromium에서 경로 입력, 연구 설정 변경, 연구 실행, 실험 독립 재현, 가설 및 작업 화면, 비교 평가와 최근 폴더 재접속을 확인했다. 모바일 폭에서도 페이지가 가로로 넘치지 않았고 루프백 이외의 요청은 없었다. Rust 실행 파일을 사용하는 기본 Windows 폴더 선택창은 실제 대화상자가 열리고 Escape로 닫힌 뒤 취소 상태가 반환되는 것을 확인했다.

현재 구현에서 범위가 제한된 영역은 고급 철학 Validator, 별도 LLM Meta-Reviewer, 실제 사내 데이터 조회 및 실험, 광범위한 데이터 접근 어댑터, 여러 프로세스가 공유하는 GJC 세션, 장기 기억 통합, 실제 LLM 기반 비교다. 로컬 운영자가 승인한 제안도 Control Plane 정책을 다시 검사한다. SDK 및 native 세션 검증을 먼저 완료한 후 같은 고정 평가 계약에서 사내 모델로 비교를 재실행한다.
